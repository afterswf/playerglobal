# playerglobal

This is [Mesmotronic](https://mesmotronic.com)'s fork of [awayfl/playerglobal](https://github.com/awayfl/playerglobal) for
[AfterSWF](https://github.com/afterswf/embed), published as [`@afterswf/playerglobal`](https://www.npmjs.com/package/@afterswf/playerglobal).
Its fixes are listed in [AfterSWF's README](https://github.com/afterswf/embed#more-advanced-as3-content).

It keeps the original package names in its imports, so install it, and any other afterswf packages you use, under
their original names with npm aliases:

```sh
npm install @awayfl/playerglobal@npm:@afterswf/playerglobal
```
